# Build Hubs
Android app that copies defined fields from a source PDF into a supplied one-page insurance PDF template.

## Current mapping
- בעלים -> שם בעל הפוליסה + large bottom name
- תעודת זהות -> מס' זהות / ח"פ + large bottom ID
- מספר רכב -> מס' רישוי
- מען -> כתובת בעל הפוליסה
- שנת ייצור -> שנת ייצור / מועד עליה לכביש
- נפח -> נפח מנוע / הספק
- תוצר -> שם היצרן והדגם
- מספר שילדה -> מס' שילדה

## Build with GitHub Actions
Push the project to GitHub and run the included workflow.
